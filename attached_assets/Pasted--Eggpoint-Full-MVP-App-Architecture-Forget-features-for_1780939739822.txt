# 🥚 Eggpoint  — Full MVP App Architecture

Forget features for a moment.

The question is:

> **What is the shortest path from egg production to money?**

Every screen must support that mission.

---

# SYSTEM ACTORS

There are only 5 users initially:

| User        | Role             |
| ----------- | ---------------- |
| Farmer      | Creates supply   |
| Aggregator  | Moves supply     |
| Agent/Kiosk | Sells supply     |
| Buyer       | Creates demand   |
| Admin       | Controls network |

```text

├── Aggregator Mode
├── Agent/Kiosk Mode

└── Admin Mode
```


# 🥚 EggLoop OS — Database & Backend Architecture (Farm ID + QR Trust System)

The biggest mistake would be trying to build this like a normal e-commerce app.

You are not selling eggs.

You are building a **Trust Ledger for Food Movement**.

The database should answer one question:

> **"Where did this egg come from, who touched it, and where is it now?"**

Everything else is secondary.

# HOW QR SYSTEM WORKS

Farmer creates batch.

```text
100 crates
```

System creates:

```text
Farm ID

RIV-PHC-0001
```

and

```text
Batch ID

EG2406080001
```

---

Backend generates:

```text
QR_URL

eggloop.app/b/EG2406080001
```

---

When scanned:

Backend loads:

```json
{
 "farm":"RIV-PHC-0001",
 "batch":"EG2406080001",
 "collected":"2026-06-08",
 "freshness":"96",
 "status":"ACTIVE"
}
```

---

# FRESHNESS SCORE ENGINE

Simple formula.

```text
100
-
(days_since_collection × 3)
```

Example:

```text
2 days old

100 - 6

94
```

Display:

```text
98-100 Fresh

90-97 Very Fresh

80-89 Good

Below 80 Aging
```

No AI needed.

---

# SEARCH SYSTEM

User types:

```text
Fresh eggs in Port Harcourt
```

Backend query:

```sql
SELECT *
FROM listings
WHERE status='ACTIVE'
ORDER BY freshness_score DESC;
```

Later add:

* location
* price
* rating

# AUDIT TRAIL (VERY IMPORTANT)

Ever.

Instead:

```text

ARCHIVED

CANCELLED
```

Keep history forever.
